## Faults found by the live runs and fixed

1. The opencode provider refused every loop call (`MissingSessionID`). The loop hid the error as a schema fault. Now a failed call is recorded as `MODEL_ERROR` with its message, and each run sends its own session id.
2. The model wrote `"provisions": [""]` when it had none; every attack was rejected as citing an unknown provision. Empty entries are now no citation.
3. Claims and critical questions showed the model's aliases (E1, A1, P1). They now show the record date, the citation and the section.
4. Every argument stayed "out" because nothing answered an attack. Rounds 2 and later now reply to the last round's attacks; a grounded reply defeats its attack.
5. The duplicate check compared raw text with alias-replaced text, so identical attacks were not found (unit test).
6. A search for "2022 INSC 155" ranked a judgment with "155" in its reporter citation first. An exact neutral citation now comes first.
7. The AWS metadata has no judgment text, so a subject search of the index finds nothing. The notice says so, and web results that name an indexed neutral citation link to the court's copy.

## Mismatches and decisions recorded

- The spec said saving an authority goes through `add_authority`. As built, the agent also has `save_judgment`, which keeps the judgment's reference (`source_ref`). The spec's tool list in V4-2 is the as-built one in the build plan.
- The Studio part named "Sources" in the spec is "Search" as built: the matter already has a Sources tab.
- The research index is reference data shared by all matters, in the user data folder. It is not a matter fact, so it is outside the matter store (decision 4 covers matter facts).

## Not verified

- No owner proof task on a real brief (lesson L3).
- High Court indexing ran in the offline tests and the live listing, but a full court-year index was not built live (a large court is tens of megabytes of range reads).
- The loop's arguments were not reviewed by a lawyer. Their quality on a real matter is unmeasured; the code checks prove grounding, not merit.
- The critic and opposing counsel use the same model as the generators (C1 3.11 asks for heterogeneous families; parked).
