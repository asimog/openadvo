## Known gaps and limits

- **The owner's exits are owed (lesson L3).** Phase 10: an old matter recovered; an approved precedent offered first; an outcome in the graph. Phase 11: one real brief per new pack, including a Section 34 challenge; a workflow run with its gates; a clipped scan with its quality score.
- Phase 9 is skipped and merged into phase 13. Phase 12 is the next phase of the plan; it has not been started.
- No analytics and no Hindi or other regional language, by the owner's instruction. X1, X2, U1 to U3 and L7 are removed from the catalogue.
- The new packs record an act version only where a source records it; other rows say "not recorded". They do not verify the version in the law store.
- The new skills name fixture briefs, not a gold set (questions Q-3); a model is not called by their tests. The review is deterministic.
- A document quality issue is advice about the reading. It opens a review item but does not block Notebook readiness.
- Image metrics are recorded for pages read as images. A born-digital page has no blur or skew, and the score says "image metrics not recorded".
- The OneDrive and Google Drive import reads their synced folders. There is no OAuth, no cloud credential and no link download.
- No integration ships. The registry checks what a manifest declares; it does not run an integration.
- A trigger fire starts nothing. The Review Inbox starts or dismisses it; starting sends a chat instruction that the Matter Agent carries out. The e2e test exercises the dismissal and the workflow gate; the start path is covered by the store test and the bridge, not end to end.
- The workflow runner runs through the Matter Agent's `run_workflow` tool, because a skill's tools run through Pi's `ctx.executeTool` and the tool policy. The bridge returns as soon as the chat instruction is sent; the run streams in the chat.
- The agent builder's test is shown in the editor and is not saved as a separate record.
- The new document kinds are honest frames. The substance of each draft is the skill's proposals; the frame keeps the recorded facts and the anchors.
- Not run: the live-model e2e tests (`OPENADVO_LIVE_MODEL`), the live-network tests (`OPENADVO_LIVE_NET=1`), and `npm run dist`.
