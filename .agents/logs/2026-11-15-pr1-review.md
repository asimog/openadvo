# 2026-11-15: review of PR asimog/openadvo#1 (native harness parts and the chat UI)

Branch reviewed: `origin/native-parts-finish` at `7b1968f`. The fixes were made on the local branch `pr1-review`, because `native-parts-finish` is checked out in another worktree.

## Findings fixed

| Area | Defect | Fix |
| --- | --- | --- |
| `src/main/helpers.ts` | A helper whose session could not start was marked failed in memory, but the window and `helpers.json` still said "running". | The failure path calls `changed()`, writes the partial output and saves `helpers.json`. |
| `src/main/helpers.ts` | `restore()` marked a running helper "interrupted" but did not save it, so every later restart showed the same "Interrupted" line. | `restore()` saves the file when it marks a helper interrupted. |
| `src/main/tool-policy.ts` | Two calls to one tool in one message both showed a card, even after the first answer was "Allow for this conversation". | The queued call checks the allowed set again and runs without a card or a log line. |
| `src/main/agent.ts`, `tool-policy.ts` | The party list was read once when the session opened. A party added later was not checked by the party rule. | The policy reads the parties at each `web_search` or `web_fetch` call. A read error fails closed. |
| `tests/unit/agent.test.ts`, `firm-agent.test.ts` | The test hosts had no `planStrength`, so 9 tests failed when the session opened. | The hosts give `planStrength` and `partyRule`. |
| `tests/unit/agent-runs.test.ts` | The test expected the removed "Tool failed: …" line. | It checks that the tool row has status `error`, the error text and a duration. |

New unit tests: two queued approvals, a party added late, restart reported once, a helper that cannot start.
