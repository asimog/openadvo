## 2. What was built

**Tool calls.** Every tool call is a role `tool` message with `tool: { name, target, status, durationMs, error }`. The window groups a run of calls into `ChatToolCalls` inside one assistant message. A call starts as running and becomes complete or failed in place. The target is the query, URL, source, task or other short argument.

**Helper work.** Each helper is one card (`ChatSystemMessage` with a muted `Card`): name, type badge, status, progress lines, its question, its own tool calls (`ChatToolCalls`) and the advocate's Stop and Steer. Helper tool calls are reported by the helper wrapper, so they show even after a background `start_helper` returned, when the parent's event stream no longer carries them. The Final Recap is a `ChatSystemMessage`. The status line keeps the plan, the helper count, the helper menu and Use results.

**No per-run cost line.** `finishRun` no longer writes "This run: …" into the chat. The numbers are in the trace, the Context tab, `/cost` and the CSV.

**Context tab.** The chat has two tabs, Chat and Context. The Context tab's icon is a usage ring and its end content is the token count. The panel lists: Session, Session id, Messages, Provider, Model, Context limit, Total tokens in context, Usage, Input tokens, Output tokens, Cache read, Cache written, Cache hit, Cost (last run), Runs and Helpers in the matter, Total tokens and Total cost in the matter, and the helpers now. Compact now is in the panel. The numbers come from `ContextMeter`, the new `lastRun` and `cost` fields of `ChatState`, and the `COST_EVENT` after a run.

**Settings sidebar.** The settings page is the `LayoutSidebarLayout` frame: a header, a section panel, a scrolling content area and a footer. The sections are Appearance, Pi extensions, Tool permissions, Plan, Mailbox, Research sources, Contacts, Diagnostics, Filing manifest key, Folders, Versions and Keyboard shortcuts. A click selects the section and scrolls to it; all sections stay on the page, so the older tests that expect several sections at once still pass. A footer says changes save as they are made.
