# Specs

One spec per step, written when the step starts (lesson L1). A spec is one page. It names its feature ids from [../features.md](../features.md), its inputs, its outputs, its checks, and the real task the owner completes to call it done (lesson L3).

No spec is written yet for the new plan. The first one is the Phase 1 stores and policy step ([../build-plan.md](../build-plan.md) section 3).

The specs of the earlier rounds (v0 to v5) are in [../archive/2026-11-15/specs/](../archive/2026-11-15/specs/). They describe the code that exists, and govern nothing.
