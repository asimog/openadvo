# v3 spec: a finished, polished application

Status: started 2026-11-14 on the owner's instruction ("move to v3 of the specs and continue building till a final polished product is made"). The instruction overrides build-plan rule B6 for this round. Sources: a visual review of the built application (screenshots of v2), the parked ideas M-02 to M-04 and P9 in [../parking.md](../parking.md), and [../advocate-workflow.md](../advocate-workflow.md) sections 1, 10 and 12 and Appendix B-C.

v3 adds no new legal capability. It makes the existing ones easy to find, to follow and to trust. The earlier specs still hold. The decisions in [../decisions.md](../decisions.md) are unchanged.

## V3-1. Matter progress (workflow 1 and 12)

- The Matter tab opens with the matter's progress: one row per stage of the workflow (record, Notebook, research and conference, drafts, verification, filing set, filing). Each row has a state (not started, in progress, done, blocked) computed from the records, and the next action in one sentence.
- The progress is computed by a plain function from records the application already holds. It decides nothing and changes nothing.

## V3-2. Review inbox (parking M-03; workflow 5H, Appendix C 3)

- A "Review" tab lists everything that waits for the advocate in one place: open review items, candidate events, open date conflicts, document types not confirmed, candidate record-table cells, memory proposals and undecided agent changes. The tab label shows the count.
- Items that block drafting or filing come first, under "Blocks the work". The rest follow under "Other".
- Each row opens the place where the advocate decides it. The keys `j` and `k` move between rows and `Enter` opens one.

## V3-3. Command bar (parking M-04)

- `Ctrl+K` (`Cmd+K` on macOS) opens a command bar. It finds matters, tabs of the open matter, actions (new matter, add files, generate a draft, settings) and source lines (the matter's line search).
- Arrow keys choose, `Enter` runs, `Escape` closes. A command does only what its button does.

## V3-4. Settings

- A "Settings" item in the side navigation opens one page: appearance (follow the system, light or dark), the authorised mailbox (moved from the Filing tab, which keeps a link), the fingerprint of the manifest signing key, the folders the application uses, the versions of the application, Electron, Euro-Office and the validator, and the keyboard shortcuts.
- The appearance is saved in `settings.json`.

## V3-5. Matter export (backup)

- "Export matter" on the Matter tab writes one ZIP file where the advocate chooses: a consistent copy of `matter.db`, every blob, the filing sets, `memory.md` and the chat files. An export is an event in the matter.
- The export never includes credentials, settings or the signing key.

## V3-6. Finish and consistency

- Dates in the Notebook views are shown as `dd.mm.yyyy`. An inferred date shows the mark "inferred" and how it was inferred (Appendix B-C).
- The chat dock of a matter with no messages shows what the agent can do and the workflows to start with.
- Notices close on their own when the advocate changes tab, and can be closed.
- The window title names the open matter.
- Buttons keep their own width; tables fit the view without a sideways scroll at the default window size; the landing page says "Attach files".

## V3-7. A build to install (decision 1, 9)

- `npm run dist` makes a folder that runs the application without the development tools, with the vendored Euro-Office, the validator and the voice model inside it. It uses `electron-builder` with the Electron already installed, so the build downloads no other Electron.
- A smoke test starts the built folder and checks that the window opens and a matter can be made.

## Not in v3

Code signing of the installer, automatic updates, and installers for other operating systems need the owner's certificates and machines. They go to [../parking.md](../parking.md).

## Proof task

The owner installs the build from `npm run dist`, works one real brief from the progress view and the review inbox to a verified filing set, and exports the matter.
